# 후속 작업: 녹취 품질 개선 대응

기본 STT 전처리/노이즈 감소 비교가 끝난 뒤 진행할 항목이다.

## 예약 항목

1. 스테레오 녹취 대응
   - 상담원/고객 채널이 분리된 스테레오 파일을 각각 mono로 분리
   - 채널별 전사 후 시간순 병합
   - 화자 라벨 표시

2. 코덱 변경 대응
   - 운영 녹취 코덱/비트레이트별 샘플 수집
   - MP3, WAV PCM, Opus/WebM, FLAC 비교
   - 동일 통화 기준 WER/누락/왜곡 비교

3. 서버측 전처리 후보
   - loudness normalize
   - high-pass/low-pass 필터
   - 무음 구간 감지
   - 채널 선택 또는 채널 분리

## 현재 범위에서 제외한 이유

현재 테스트는 이미 녹취된 저비트레이트 전화 파일에서 가능한 최선의 STT 조건을 찾는 것이 우선이다. 녹취 방식과 코덱 변경은 운영 녹취 파이프라인 조정이 필요하므로, 기본 STT 비교가 끝난 뒤 별도 단계로 진행한다.
